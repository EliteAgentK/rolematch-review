```
   │
   ├─► model call 1: the parts only the model reads well, answered by LINE NUMBER
   │     roles as {title line, employer line, date line}; education the same; agency;
   │     skills and certificates only where the rules' reading is thin (decided per field by measurement)
   │     a long CV: its sections on the Mac and the PC at the same time
   ▼

       contact and identity checks (instant, no model)
   │
   ├─► model call 2, only if something is unresolved: ONE question covering every unclear place
   ▼
 corrections the CV's own words prove are APPLIED, marked "corrected by the model", original kept,
 one click to undo; anything unproven goes to the recruiter as before
   ▼
 publish (a candidate still never reaches the panel before this point)
```

## Decisions for the owner

* A fixed address needs a named Cloudflare tunnel, which needs a domain on Cloudflare (free plan, but the domain is yours to choose).
* Live CVs read on the PC means a tenant's document text crosses the home network to the PC, encrypted, held only while being read. Proceeding on that basis unless you say otherwise.
* The Mac doubles as your desktop. The model will always be slower while it is short of memory; a machine that does only this is the lasting answer.
